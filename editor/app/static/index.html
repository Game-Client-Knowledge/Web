Contribution guide

知识库共建完整引导

1 / 7

01 · 开始之前

先理解账号权限和本地双树

Base Tree 是不可修改的远程基线，Current Tree 是本机当前内容。 编辑、新建和删除只改变 Current Tree，不会直接写入 GitHub main。

  • 顶部状态显示当前编辑策略和本地更改数量。
  • 策略要求 GitHub 认证时，先点击“绑定 GitHub”。
  • 文件位置、标题和目录必须符合建设规范。
打开建设规范

02 · 编辑文档

从资源树打开并编辑完整文件

在左侧资源树选择文件。编辑器会从 Base Tree 加载完整内容， 修改后自动写入 Current Tree；预览和源文件视图可随时切换。

  • “保存到本地”不会上传服务器或修改 main。
  • “撤销更改”将当前文件恢复到 Base Tree。
  • 删除现有文件只是记录 D 状态，提交后才从仓库移除。

03 · 新建结构

区分大模块、专题目录和内容文件

资源管理器上方提供三种创建入口。创建结果会立即进入 Current Tree，并出现在左侧导航和“更改”列表中。

  • 新增大模块：选择程序或策划赛道，创建顶级内容类型。
  • 新增专题：在现有模块中创建目录和 README。
  • 新建文件：填写完整仓库路径和一级标题。

模块 README 是模块落地页，不会重复显示为普通文件。

04 · 评论协作

在知识站阅读页评论和回复

评论发生在知识站文档页，而不是工作台。点击文档标题旁“评论” 可讨论整篇内容；选中正文后可创建带原文引用的评论。

  • 支持回复、@ 提及成员和评论邮件通知。
  • 评论不进入 Current Tree，也不需要提交 PR。
  • 作者或管理员可删除评论。
前往知识站

05 · 检查更改

在“更改”标签逐个审阅 A/M/D

“更改”列表展示 Current Tree 相对 Base Tree 的全部差异。 打开文件可查看完整源文件的行级 Diff。

  • A / M / D 分别表示新增、修改、删除。
  • “同步远程”只在工作区干净时更新两棵树。
  • “释放缓存”会永久清空本机未提交更改。

06 · 发布更改

统一创建分支、commit 和 Draft PR

在右侧“统一提交”填写提交头、PR 标题和说明，再提交 Current Tree 的全部更改。系统只发送变更文件的完整内容。

  • 分支为 web/用户名/提交头；同名时会询问是否覆盖。
  • Draft PR 不会直接写入 main，仍需管理员审核。
  • main 前进产生的冲突由 GitHub PR 正常展示和解决。

07 · 查看贡献

跟踪提交状态和已发布贡献

“最近提交”显示个人 PR、分支和处理状态。PR 合并并发布后， 首页贡献看板会更新新增、修改、删除行数。

  • 主页支持全部、程序、策划赛道筛选。
  • 累计和最近 7 天分别反映总贡献与近期活跃。
  • 贡献空间可查看星体等级、亮度和文档关系。
