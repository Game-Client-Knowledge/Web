First login guide

开始参与知识库共建

1 / 4

01 · 先读规范

目录结构决定导航结构

提交前请确认文件位置、Markdown 标题、命名和内容范围。 规范页面包含知识、面经与代码示例的完整约定。

打开建设规范

02 · 加入组织

申请后还要接受 GitHub 邀请

加入页会自动创建组织邀请。收到 GitHub 邮件或通知后， 仍需手动接受，账号才会成为组织成员。

前往加入页面

03 · 页面内编辑

在知识库右上角进入或退出编辑模式

进入后可直接修改当前文档，也可在模块中创建子模块和文件。 保存只会写入你的个人草稿，不会直接修改 main。

04 · 统一提交

检查 A/M/D 更改并创建 Draft PR

填写提交头、标题和说明后，系统会创建个人分支、 一个 commit 和一份等待审核的 Draft Pull Request。
